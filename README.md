🎓 Student Grade Calculator

A simple Student Grade Calculator built with Python that calculates a student's total marks, percentage, and grade based on marks obtained in five subjects.

This project was developed to practice Python programming fundamentals through a practical, real-world application.

✨ Features

- 👤 Accepts the student's name
- 📝 Takes marks for five subjects
- ➕ Calculates total marks
- 📊 Calculates overall percentage
- 🏆 Assigns a grade based on percentage
- 💻 Simple command-line interface
- ⚡ Easy to use and understand

🛠️ Technology Used

- Python 3

📚 Concepts Practiced

This project demonstrates:

- Variables
- User Input
- Arithmetic Operations
- Conditional Statements
- "if", "elif", and "else"
- Basic Program Flow
- Command-Line Interaction

📋 Grading Criteria

Percentage| Grade
80% and above| A+
70% – 79%| A
60% – 69%| B
50% – 59%| C
40% – 49%| D
Below 40%| F

▶️ How to Run

1. Clone the Repository

git clone https://github.com/tayyabsb/python-student-grade-calculator.git

2. Navigate to the Project Directory

cd python-student-grade-calculator

3. Run the Program

python student_grade_calculator.py

💻 Example

===== STUDENT GRADE CALCULATOR =====

Enter student name: Tayyab
Enter marks for Subject 1: 85
Enter marks for Subject 2: 78
Enter marks for Subject 3: 92
Enter marks for Subject 4: 81
Enter marks for Subject 5: 88
